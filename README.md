# 浮生三國

以《三國演義》為背景的繁體中文人生模擬網頁遊戲。

## 遊玩

隨機出生於農民、貧民、商人、軍人或世家大族（貧民45%，其餘各13.75%），從幼年選擇一路發展至任官、婚育、起義與建國。遊戲包含演義勢力主線、名士關係、職官資料庫，以及14州區80座真實城池的簡化征戰模式。

直接開啟 `index.html`，或使用本儲存庫的 GitHub Pages 網站遊玩。遊戲無須建置、後端或 API 金鑰。

## 存檔

存檔僅儲存在各玩家的瀏覽器內。更換裝置、瀏覽器或網址不會自動移轉存檔。清除網站資料會清除存檔。

## 內容與來源

演義事件以《三國演義》章回為參考；玩家的人生、權謀、婚育、暗殺、起義及建國屬架空支線。數值及生育結果為遊戲機率，不是歷史統計或醫療判定。

職官庫收錄285項有原文章回出處的官職及稱號；州郡以漢末框架結合三國沿革註記。勢力歸屬、官階及戰鬥均作遊戲簡化，並非完整同年行政或官制復原。

- [《三國演義》章回目錄](https://zh.wikisource.org/zh-hant/三國演義)

## 部署

GitHub Pages 選擇從 `main` 分支的根目錄發布即可。`index.html` 包含全部程式、樣式與遊戲資料；`.nojekyll` 用於直接發布靜態檔案。

## 新增玩法

獨立君主可投降或接受招安；各勢力更積極反攻，攻城依年度戰況調整。原角色去世後，可由一位在世子女延續一世；世界年份、領土與家譜保留，一般官職不世襲。地方判案與官員犯罪加入死刑覆核及成年男性宮刑改刑的架空分支。

所有出身與路線均可能接觸鮮卑、匈奴、烏丸、高句麗、倭及羌氐諸部的交流事件，依身分區分幼年見聞、商旅、奉命出使及君主遣使。參考《三國志》卷30、26，超出史實年份的互動明示為架空；宮刑參考卷13刑制討論，不宣稱三國普遍施行。
