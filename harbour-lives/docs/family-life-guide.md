# 香江浮生 0.4：家族、教育與年代機遇

公開遊戲：[香江浮生](https://leepingyo.github.io/sanguo-life/harbour-lives/)

## 本輪已開放

「家族人生」為首頁預設模式。可由1842、1853、1887、1905、1950或1971年開始，年度流轉至1997年6月30日。六卷劇情與典藏每週生活保留為獨立篇章；三種模式各自存檔。

玩家可選18歲入世或6歲開始。水手須至少18歲；幼年角色有虛構監護人分擔家計。性別會影響部分歷史學校的路線，能力分數不按性別設置高低。

## 工作與學業自動流轉

選擇「營生與工作」「學業與語言」「家庭與傳承」「街坊與交遊」作年度重心，按自動流轉即可。每年結算收入、生活、利息、學費與學習。工作、教育、錄取、歷史機遇及家庭協商會停住時間，玩家選擇後可再繼續。也可手動度過一年。

學程申請有待回覆狀態；同一人不可重複申請或同時修讀兩個課程。事件保存於存檔，重新整理仍須處理，不會藉刷新略過錄取或機遇選擇。離開頁面時暫停自動時間。

家庭帳本在桌面畫面右側，持續顯示現金、欠款、上年收入、上年總支出與淨值。小螢幕改為人物之後、主要紀事之前，避免擠壓閱讀。其數字為「生活預算點」，不冒充跨十九、二十世紀都固定的銀元、港元、英鎊或匯率。

## 本地教育

| 路線 | 年代與條件 | 完成後的遊戲效果 |
|---|---|---|
| 私塾／家庭讀寫 | 1842—1970；6歲以上 | 基礎讀寫進度；不是學校文憑 |
| 官立／資助小學 | 1971年起；6—15歲 | 六年小學階段；不收遊戲學費，仍有生活成本 |
| 聖保羅書院早期路線 | 1851—1940；本期男性路線 | 中等學業進度；歷史班制簡化 |
| 中央書院／後來皇仁書院 | 1862—1940；本期華人男童路線 | 中等學業進度；早期校名與後來名稱分開說明 |
| 成人中英文讀書班 | 16歲以上；虛構班級 | 可累積中等準備分數，不是真實認可中學學歷 |
| 本地資助中學銜接 | 1946年起 | 六年中等學業；1978年後把初中免費部分折算為平均年費減半 |
| 香港西醫書院 | 1887—1911；本期男性路線 | 五年醫學學程；不自動授予執業資格 |
| 香港大學文科方向 | 1912年起；女性自1921年起 | 四年遊戲化高等學程 |
| 香港中文大學文科方向 | 1963年起 | 四年遊戲化高等學程 |

學力0—3是遊戲進度。年代、部分招生限制與學校存在有史料支持；具體入學年齡、分數、錄取機率、費用、課程年期及獎助額屬簡化，不是任何院校特定年的完整招生章程。成人讀書班的進度在遊戲中可用於申請，不代表真實院校會承認它。

## 留學已可完成

英國UCL文科方向開放申請、下一年錄取回覆、接受或放棄學額、啟程到倫敦、按年繳費與修課、完成學程，以及留外或付回程費回港。女性路線自1878年起；不把當時文科開放推論成所有醫學課程同時開放。

學費不足會停學並保留進度；退出學程後，未完成課程須重新申請。遊戲助學額需要較高學習分數，是虛構機制，並非某項真實歷史獎學金。留外不自動有當地工作收入、合法工作權、國籍或居留資格。海外結業亦不自動換成香港專業執照。

## 家族可以建立與接續

玩家可設定家族稱號，與成年虛構角色共同生活，迎接孩子或接納需要家庭的孩子。每代上限四名子女；每次家庭擴展按年安排，不可在同年重複操作。每名成員保存出生年份、家長連結、所在地、學習能力、學程與完成紀錄。

可以替子女申請本地或海外教育；子女成年後能接續成為主角。改變的是玩家視角，既有成員仍在家族樹中。監護人不被當成主角的子女。姓氏與家庭稱號分開，伴侶保留自己的姓名。

共享家庭預算是玩法，不等於婚姻財產或遺產的法律分配。早期共同生活不直接認定為有效婚姻；可整理婚姻形式資料。因本模式只記年份，改革後登記婚姻情節從1972年度開放，以避免把1971年10月7日改革提前套到整個1971年。收養屬劇情標記，尚未完整模擬法律程序。

非主角成員90歲起離世、主角90歲交由成年子女接續或結束故事，為固定遊戲壽命，不是歷史死亡率或個人健康預測。尚未模擬完整遺產爭議、監護權及海外家庭法。

## 歷史人物與隨機機遇

| 事件 | 年份與所在地 | 設計界線 |
|---|---|---|
| 太平天國戰事、旅人與家書 | 1851—1864；香港 | 協助尋人、住處或核對消息；不把香港變成太平天國都城 |
| 洪仁玕在港背景下的見聞 | 1853—1857；香港 | 虛構交會；不讓洪秀全常居香港 |
| 西醫書院附近的孫中山 | 1887—1892；香港 | 學習分數及機率門檻；不保證所有人遇到，不偽造名人語錄 |
| 同盟會刊物與虛構支持者 | 1905—1911；香港 | 不是1905年前已存在的組織，也不假定孫中山可自由出入香港 |

每個家族各項機遇只出現一次，由種子隨機數決定；讀取同一待處理事件不會重抽。機率為玩法設定，不代表與真實人物相遇的統計。玩家不能憑選項改寫已知大事件，也不會自動成為歷史組織的有名成員。

## 歷史背景與下一步

1941—1945年暫停本地教學進度並縮減收入、增加生活壓力，為戰時簡化模型。它未完整實裝日佔法律、軍票、配給、拘留或各類學校的實際安排，不能視為完整戰爭模擬。

本輪新增功能以家族人生模式呈現。六卷原創劇情與典藏每週模式保存原有玩法，沒有把既有存檔直接轉成155年家族資產。回憶錄逐頁閱讀與授權查核仍待後續進行。
